## Agent Brief

**Category:** enhancement
**Summary:** Upgrade the DFTrans raw extractor to support 2–4 worker threads with 1.0s per-worker polite delay, exponential backoff on HTTP 429/5xx/network errors, master stop inventory download, and atomic resumable caching.

**Current behavior:**
Two overlapping scripts exist in the repository: a legacy `harvest_dftrans.py` (which uses 4 threads with a `0.15s` delay, no retry/backoff, writes to `data/raw_lines`, fetches `/parada/geo/paradas`, and includes a deprecated `brasiliamobilidade.com.br` HTML fallback) and `extract.py` (which writes atomically to `data/raw/`, includes retries with exponential backoff, but runs strictly single-threaded and does not download the master stops GeoJSON).

**Desired behavior:**
Unify raw extraction in `extract.py` so it downloads the global stop inventory (`/parada/geo/paradas` -> `data/all_stops_df.geojson`) and processes all active lines from the catalog concurrently using 2–4 worker threads with a `1.0s` polite delay per worker and exponential backoff on rate limits (`429`) or server/network errors (`5xx`). Every line payload must contain `metadata` (`/linha/numero/{numero}`), `percurso` (`/percurso/linha/numero/{numero}/` in `EPSG:3857`), directional `paradas` (`/parada/linha/{sequencial}/geo`), and `horarios`.

**Key interfaces:**
- CLI flags: `--catalog`, `--lines`, `--limit`, `--force`, `--delay` (default `1.0`), `--workers` (default `4`, configurable `2–4`), `--retries` (default `3`), `--backoff` (default `2.0`)
- Output artifacts: `data/all_stops_df.geojson` and `data/raw/{safe_line_number}.json`

**Acceptance criteria:**
- [x] Running the extractor downloads `data/all_stops_df.geojson` (~5,466 features) once unless `--force` is specified
- [x] Multi-threaded execution runs with 2–4 workers and enforces both a `1.0s` polite delay per worker and exponential backoff (`backoff * 2**(attempt - 1)` or `backoff * attempt` with jitter) on HTTP `429`/`5xx`/timeout errors, using thread-safe HTTP sessions (`requests.Session` per worker thread)
- [x] Interrupted runs skip already-cached `data/raw/{line}.json` files and leave zero partial/corrupt files on disk
- [x] No live requests are made to the deprecated `brasiliamobilidade.com.br` domain

**Out of scope:**
- Coordinate reprojection (`EPSG:3857` -> `EPSG:4326`) or `shapely` linear referencing (handled offline in Ticket 04 so `data/raw/` preserves exact upstream payloads)
