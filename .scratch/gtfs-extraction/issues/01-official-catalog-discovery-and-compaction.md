# 01: Official Active Line Catalog Discovery & Catalog Compaction

**What to build:** An automated, repeatable line catalog discovery procedure that retrieves all currently active Federal District (`Semob-DF`) bus line numbers directly from official transit backends without relying on third-party `brasiliamobilidade.com.br` DOM scraping, filters out interstate `ANTT`/Entorno lines, and produces a compact, deduplicated master catalog JSON.

**Blocked by:** None (can start immediately)

**Category:** enhancement
**Status:** completed

- [x] A repeatable catalog discovery command queries official endpoints (sweeping prefix combinations or operator/basin endpoints on `sistemas.dftrans.df.gov.br` to bypass the 30-record `/linha/find/{termo}` search cap, and/or cross-referencing the official `dfnoponto` / Bus2 master route list) to enumerate all active DF urban bus lines
- [x] Interstate `ANTT` / Entorno lines (`data-semob="0"` or non-Semob jurisdiction) are filtered out or explicitly flagged so the urban DF GTFS scope remains clean
- [x] The resulting catalog is deduplicated by line `numero` and serialized in a compact JSON representation (stripping redundant third-party `url`, `slug`, and duplicated line number prefixes in `descricao`)
- [x] The extractor loads the compacted catalog seamlessly without breaking existing CLI flags

## Agent Brief

**Category:** enhancement
**Summary:** Replace static/third-party line catalog scraping with official active line discovery and compact the catalog schema.

**Current behavior:**
The official active line catalog is generated by `discover_catalog.py`, producing 933 deduplicated DF urban bus lines with clean descriptions, eliminating 34 ANTT interstate routes, and mapping them to Bus2 routes.

**Desired behavior:**
Provide an official catalog discovery routine that enumerates all currently active `Semob-DF` lines directly from official government sources (e.g., prefix expansion against DFTrans endpoints and/or the official `dfnoponto` / Bus2 master route index), retains `Semob-DF` jurisdiction filtering (`semob` urban lines vs. `ANTT` interstate lines), and stores a compact, deduplicated JSON catalog.

**Key interfaces:**
- `load_catalog()`: Should accept both the new compact catalog schema and legacy object lists so extraction runs remain backward-compatible.
- Catalog JSON schema: Deduplicated records keyed by `numero` with minimal metadata (`numero`, clean `descricao`, and jurisdiction/active status).

**Acceptance criteria:**
- [x] Official catalog discovery retrieves all active DFTrans / Semob-DF line numbers without requiring live DOM access to `brasiliamobilidade.com.br`
- [x] `LIMIT 30` truncation on `/linha/find/{termo}` is either bypassed (via finer-grained prefix/category enumeration) or avoided via an un-capped official index endpoint
- [x] Interstate `ANTT` lines are excluded from the default DF urban extraction list
- [x] The catalog JSON file size and line count are compacted by removing redundant third-party fields (`url`, `slug`, repeated prefix strings)

**Out of scope:**
- Per-line geometry and stop downloading (handled in Ticket 03)
- GTFS table synthesis (handled in Ticket 04)
